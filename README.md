# Leap

A free, private desktop AI app. Leap sends each prompt to the cheapest model
that can actually handle it, out of 330+ models from 50+ labs, and you can
start at $0 on free models. Your keys and your chats stay on your machine.

**Download:** [leapsystems.eu/download](https://leapsystems.eu/download)
(macOS, Windows, Linux). Each installer's SHA-256 is published there, so you
can check the file you got is the file we built.

This repository holds the published installers only. The app's source is not
public.

- **Questions, ideas, show what you built:** [Discussions](https://github.com/leapSystems/leap-releases/discussions)
- **Something broken:** [open an issue](https://github.com/leapSystems/leap-releases/issues/new/choose)

  security@leapsystems.eu instead.

## Updates

Leap checks this repository for new releases and offers to install them. Every
release is listed under [Releases](https://github.com/leapSystems/leap-releases/releases).
